章　产品概述</h1><h2>1.1 产品定位与背景</h2><p><b>AI 问书</b> 是一款面向出版机构的「把纸书变成可对话 AI」的知识变现产品。读者扫描书籍封底二维码（或打开分享链接）即可进入该书专属的 AI 会话，用自然语言提问，由系统基于该书知识库检索后给出<b>带多模态素材与章节溯源</b>的回答；机构（出版社）在后台把书籍加工为知识产品（KP）、配置 Agent 人设与定价权益、生成二维码并查看经营数据；平台超管统一管理机构、账户、大模型与全局策略。</p><p>产品的商业闭环是：<b>机构把内容资产 KP 化 → 通过二维码触达读者 → 读者在问答中触发付费墙（会员订阅 / 永享买断 / 兑换码）→ 资金进入机构账户</b>。平台以多租户 SaaS 形态为机构提供能力底座与大模型用量。</p><h2>1.2
